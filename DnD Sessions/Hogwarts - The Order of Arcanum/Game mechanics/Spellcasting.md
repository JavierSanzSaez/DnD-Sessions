### **1. Spellcasting Experience Stages**

Each character has a proficiency level for every School of Magic. This level affects their attack rolls.

|Experience Stage|Description|Modifier|
|---|---|---|
|**Untrained**|The character has never studied or practiced this school.|**–2 penalty**|
|**Basic Understanding**|The character has limited exposure; theory but little practice.|**–1 penalty**|
|**Competent**|The character has had some practice and understands the foundations.|**+0 (neutral)**|
|**Proficient**|The character has been trained and actively uses spells from this school.|**+1 bonus**|
|**Mastery**|The character is an expert or specialist in this magical discipline.|**+2 bonus**|
